# CUSTOMER-SERVICE-REQUEST-ANALYSIS
📊 Customer Service Request Analysis using Python

## 🚀 Project Overview
This project performs Exploratory Data Analysis (EDA) on NYC 311 Service Request dataset to understand customer complaint trends, locations, and service patterns using Python.


## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab


## 📂 Dataset
NYC 311 Service Request dataset including:
- Complaint Type
- City
- ZIP Code
- Created Date
- Status

## 🔍 Data Cleaning
- Handled missing values  
- Converted date columns into datetime format  
- Removed inconsistent and irrelevant data  


## 📊 Analysis Performed
- Complaints per City  
- Complaint Type Distribution  
- Top ZIP Codes Analysis  
- Data visualization using charts  


## 📈 Key Insights
- High number of complaints are concentrated in specific cities  
- Few complaint types dominate the dataset  
- Certain ZIP codes have higher complaint frequency  
- Uneven distribution of complaints across locations  


## 🚀 Future Scope
- Time-based analysis  
- Interactive dashboard  
- Map visualization
